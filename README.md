# itsazibfarooq.github.io

Personal academic website of Azib Farooq, built with Jekyll and the [al-folio](https://github.com/alshedivat/al-folio) theme (MIT).
Pushing to `main` builds the site with GitHub Actions and deploys it to the `gh-pages` branch.

Edit content in: `_pages/about.md`, `_news/`, `_bibliography/papers.bib`, `_data/cv.yml`, `_projects/`.
